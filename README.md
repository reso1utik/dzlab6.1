# Домашнее задание к работе 6.1

## Условие задачи

Составить программу, которая проверяет, принадлежит ли заданная пользователем точка с координатами (x, y) заданным закрашенным (заштрихованным) областям, показанным на рисунках в табл. (**Вариант 26**), и выводит на экран сообщение.

## 1. Алгоритм и блок-схема
### Алгоритм решения
1. **Начало**
2. Задать исходные данные: 
   - `x` (координата по оси абсцисс, вещественное число)
   - `y` (координата по оси ординат, вещественное число)
3. Проверить попадание в три подобласти:
   - `in_top` = (x >= -1 и x <= 5) и (y >= 2 и y <= 4)
   - `in_middle` = (x >= -1 и x <= 2) и (y >= -2 и y <= 2)
   - `in_bottom` = (x >= -4 и x <= 2) и (y >= -4 и y <= -2)
4. Вычислить итоговое условие:
   - `is_inside = in_top или in_middle или in_bottom`
5. Вывод результата:
   - Если `is_inside` истинно, вывести: "ПРИНАДЛЕЖИТ заштрихованной области."
   - Иначе вывести: "НЕ ПРИНАДЛЕЖИТ заштрихованной области."
6. **Конец**

## 2. Реализация программы

```c
#include <stdio.h>
#include <stdbool.h>

int main() {
    float x, y;
    bool in_top, in_middle, in_bottom, is_inside;

    printf("=== Проверка попадания точки в область (Вариант 26) ===\n");
    
    printf("Введите координату x: ");
    if (scanf("%f", &x) != 1) {
        printf("Ошибка ввода x.\n");
        return 1;
    }
    
    printf("Введите координату y: ");
    if (scanf("%f", &y) != 1) {
        printf("Ошибка ввода y.\n");
        return 1;
    }

    // Проверка прямоугольных зон фигуры
    in_top    = (x >= -1.0f && x <= 5.0f) && (y >= 2.0f && y <= 4.0f);
    in_middle = (x >= -1.0f && x <= 2.0f) && (y >= -2.0f && y <= 2.0f);
    in_bottom = (x >= -4.0f && x <= 2.0f) && (y >= -4.0f && y <= -2.0f);

    is_inside = in_top || in_middle || in_bottom;

    printf("\nТочка (%.2f; %.2f) ", x, y);
    if (is_inside) {
        printf("ПРИНАДЛЕЖИТ заштрихованной области.\n");
    } else {
        printf("НЕ ПРИНАДЛЕЖИТ заштрихованной области.\n");
    }

    return 0;
}
```
